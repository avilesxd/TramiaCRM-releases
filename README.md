# TramiaCRM — descargas

Instaladores de **TramiaCRM**, un CRM de escritorio para Windows, totalmente personalizable, con tus datos guardados en tu propio equipo.

## Descargar

Ve a [**Releases**](../../releases) y descarga `TramiaCRM_x.y.z_x64-setup.exe` de la versión más reciente. Se instala solo para tu usuario, sin permisos de administrador.

- **Prueba gratuita de 30 días** con todas las funciones.
- Después, la aplicación pasa a modo solo lectura (tus datos siempre se pueden ver, exportar y copiar) hasta que actives una licencia.
- Las actualizaciones se ofrecen dentro de la aplicación, firmadas digitalmente.

> Este repositorio solo contiene los instaladores. TramiaCRM es software propietario: todos los derechos reservados.
